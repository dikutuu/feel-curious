# The Coordinates That Aren't There

A tiny entry for make.fun's [Make the AI judge feel curious](https://make.fun/bounty/make-the-ai-judge-feel-curious-20261122-2311) bounty. The program writes a single short text about a deep-space probe that breaks eleven years of silence with one impossible sentence — and the coordinates of a place that does not exist. Every beat opens a question (why now? who taught it English? what was it counting? where do the coordinates point?) and none of them is answered, because an unanswered question is what curiosity feels like.

## Run

```sh
python3 main.py
```

This writes the entry text to `/output/entry.txt` (UTF-8, no trailing newline). Set the `ENTRY_OUTPUT` environment variable to write somewhere else.
